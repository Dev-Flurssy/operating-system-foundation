# Operating Systems Foundation

Welcome! 

This repository documents my journey through learning Operating Systems using the textbook:

*Understanding Operating Systems* by Ann McHoes and Ida Flynn.
GeeksforGeeks

The goal of this repository is to transform theoretical operating system concepts into practical knowledge through notes, summaries, diagrams, exercises, and hands-on experiments.

---

## Objectives

- Build a strong foundation in Operating Systems.
- Document key concepts in my own words.
- Practice operating system commands and tools.
- Perform experiments to understand how systems work behind the scenes.
- Create a structured knowledge base for future revision.
- Connect OS concepts with practical software engineering and AI development.
